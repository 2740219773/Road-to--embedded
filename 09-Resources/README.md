# 09 — Resources

这里不是“大而全”的收藏夹，只保存真正会进入学习流程的资料。

## 分类

- `GitHub-Projects.md`：公开项目与参考仓库；
- 后续增加 `Books.md`：值得完整阅读或查阅的书；
- 后续增加 `Courses.md`：课程与视频；
- 后续增加 `Tools.md`：IDE、编译器、调试器、示波器、逻辑分析仪等工具资料。

## 收录标准

一个资源至少满足一项才值得加入：

- 能把某个基础概念讲得明显更清楚；
- 有可以直接做的实验；
- 有值得学习的工程结构；
- 有高质量调试案例；
- 是官方文档、标准、datasheet 或长期可靠的参考资料。

如果只是“以后可能有用”，原则上不收录。
