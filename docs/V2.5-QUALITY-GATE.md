# V2.5 Stage 05 Quality Gate

## Formal scope

V2.5 正式建设 Stage 05 RTOS Engineer。Stage 06～08 仍是 prototype，不纳入本次完成判断。

正式闭环：

```text
Task / Scheduler
→ Synchronization
→ Race / Priority / Deadlock / Queue
→ Evidence Workbench
→ Mixed Challenge
→ RTOS Refactor Boss
→ Exit Check
```

## Evidence status vocabulary

| 状态 | 含义 |
|---|---|
| Host deterministic model verified | C11 状态模型编译并通过固定回归序列 |
| Browser interaction verified | Workbench 在目标尺寸下完成交互、键盘和控制台检查 |
| Static content verified | 课程字段、入口、路径和内部链接检查通过 |
| Real FreeRTOS / MCU / instruments not verified | 没有连接真实 RTOS、开发板、Debugger 或仪器 |

前三项不能合并描述为真实硬件验证。

## Blocking checks

从仓库根目录运行：

```powershell
node --check tools/validate-content.mjs
node tools/validate-content.mjs
```

必须阻断：

- Stage 05 四个 Mission 缺少统一闭环字段；
- Stage 05 四个 Debug Case 缺少 Evidence、Hypotheses、Experiments、Root Cause、Fix 或 Verification；
- Mixed Challenge、Exit Check、Workbench、Host Fixture 或 Evidence Pack 缺失；
- Stage 05 内部入口存在断链；
- HTML Lab 缺少 doctype、lang、viewport、共享基础样式或 aria-live 状态区；
- V2.5 状态文档互相矛盾；
- V2.5 已标记完成但没有 Host Fixture PASS 记录；
- Stage 06～08 prototype 被误标记为正式完成。

其他历史 Stage 的 advisory 不阻断 V2.5，但必须保留在检查输出中。

## Browser acceptance

RTOS Concurrency Workbench 必须在 1280×800 和 375×812 下满足：

- 无整体横向溢出；
- Scheduler、Race、Priority、Deadlock、Queue/ISR/Stack 模式均可完成基本路径；
- Tab、Select、Button、Textarea 可通过键盘操作；
- `:focus-visible` 清晰可见；
- 动态反馈包含 `role="status"` 和 `aria-live`；
- Evidence Record 可以保存、读取和清空；
- 浏览器控制台无 JavaScript 错误；
- 页面明确标注所有数值为虚拟教学模型。

## Host fixture acceptance

Host Fixture 使用确定性 C11 模型，不依赖 FreeRTOS，不创建真实线程。可用工具链时执行：

```powershell
cl /std:c11 /W4 /WX host/rtos_fixture.c host/test_rtos_fixture.c /Fe:host/stage05-fixture.exe
host/stage05-fixture.exe
```

预期输出：

```text
Stage 05 host fixture regression: PASS
```

## Final gate

只有以下条件全部满足，`09-Progress/Current.md` 才能把 V2.5 Stage 05 标记为 completed：

- 四个 Mission 完成统一闭环；
- 四个 Debug Case 字段完整；
- Mixed Challenge 和 Exit Check 可从 Stage 入口进入；
- Workbench 浏览器验收通过；
- Host Fixture 编译运行结果已记录；
- README、ROADMAP、PROJECT、Current 和 Development Plan 状态一致；
- 没有把真实 FreeRTOS、MCU 或仪器结果误报为已验证。
