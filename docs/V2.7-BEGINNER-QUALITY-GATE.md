# V2.7 Beginner Framework Quality Gate

本质量门验证“新手路线是否可以独立执行”，不把文档通过误写成真实硬件通过。

## 证据等级

| 等级 | 含义 |
|---|---|
| 文档结构已验证 | 入口、路径、字段和交叉链接通过 Node 检查 |
| 浏览器交互已验证 | HTML Lab 在目标尺寸完成基本操作 |
| PC/C 样例已验证 | Warmup C 样例经过编译、运行和输出检查 |
| Host Fixture 已验证 | 确定性 C 状态模型编译并通过固定回归 |
| 真实 MCU / 仪器尚未验证 | 未连接开发板、Debugger、万用表、示波器或逻辑分析仪 |

## 正式路线完成标准

Stage 00～05 每一阶段必须有：

```text
Entry
→ Required Knowledge
→ Mission
→ Lab / Measurement
→ Debug Case
→ Boss
→ Exit Check
→ Next Stage
```

每个正式 Mission 必须能回答：

```text
适合谁
→ 前置条件
→ 当前任务
→ 预测
→ 操作 / 观察
→ 故障
→ 证据调试
→ 需要提交什么
→ 卡住怎么办
→ 何时可以继续
```

## C 样例质量门

在有 GCC 的环境中执行：

```powershell
gcc -std=c11 -Wall -Wextra -Werror 02-Learning-Path/00-Programming-Warmup/examples/hello.c -o warmup.exe
.\warmup.exe
```

如果当前机器没有 C 编译器，只能记录为“静态检查，运行未验证”。
