# Learning Record Template

每个练习、Mission 或故障案例至少保留一份记录。不要只保存最后答案，重点保存你如何从现象得到结论。

```text
主题 / Mission:
日期:
当前 Stage:

现象 / 任务:
Expected（我原本认为会发生什么）:
我的预测:
我实际做了什么:
Observed（实际观察到什么）:

最有价值的证据:
它排除了什么假设:
仍然保留的假设:
Root Cause（根因）:
Minimal Fix（最小修复）:
Regression（回归验证）:

我现在能解释什么:
我仍然看不懂什么:
下一步查哪一页或做哪一个实验:
```

硬件 Mission 还应补充：

```text
Board / MCU:
Debug Probe:
测量工具:
接线或参考地:
软件证据:
物理证据:
```
