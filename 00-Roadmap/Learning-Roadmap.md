# Learning Roadmap

## 目标

这条路线不是为了“把所有嵌入式知识学完”，而是为了建立足够扎实的底层基础，使学习者能够看懂真实项目、参与联调、理解异常现象，并逐步具备独立开发和定位问题的能力。

## Phase 0：建立知识地图与环境

目标：先知道整个嵌入式系统由什么组成，每个部分解决什么问题。

需要理解：

- MCU、MPU、SoC、FPGA 的基本区别；
- CPU、RAM、Flash、外设、总线的基本关系；
- 裸机、RTOS、Embedded Linux 的区别；
- 编译、链接、烧录、运行、调试的大致流程；
- GPIO、UART、SPI、I2C、CAN、Ethernet 分别解决什么问题；
- 示波器、逻辑分析仪、万用表、JTAG/SWD 分别用于观察什么。

完成标准：看到一块常见 MCU 开发板，能够大致说明程序从代码到芯片运行经历了什么。

## Phase 1：C 与底层基础

重点不是重新学习全部 C 语言，而是掌握嵌入式开发最常用的部分：

- 变量、数据类型与作用域；
- 数组、字符串、结构体；
- 指针与地址；
- 函数指针基础；
- 位运算；
- `const`、`volatile`、`static`；
- 内存布局基础；
- 栈、堆、全局区的基本概念；
- 头文件与多文件工程；
- 编译与链接基础。

同时补充：

- 二进制、十六进制；
- 补码；
- 寄存器；
- CPU 执行指令的基本过程；
- 数字电路基础。

完成标准：能够读懂常见 MCU 驱动代码中的指针、寄存器、位操作和结构体写法。

## Phase 2：MCU 与 STM32

目标：真正建立“代码如何控制硬件”的感觉。

学习顺序建议：

1. 开发环境与下载调试；
2. GPIO 输入输出；
3. 外部中断；
4. 定时器；
5. PWM；
6. UART；
7. ADC；
8. SPI；
9. I2C；
10. DMA；
11. 看门狗；
12. Flash；
13. 时钟系统；
14. 低功耗基础。

每一个外设都按照同一套路学习：

**用途 → 硬件连接 → 寄存器/驱动结构 → 最小实验 → 故障实验 → 调试观察。**

完成标准：能够独立完成一个包含多个外设的小型裸机项目，并能定位常见通信和时序问题。

## Phase 3：调试能力第一次强化

开始系统训练：

- 断点；
- 单步；
- Watch；
- Memory；
- Register；
- Call Stack；
- 串口日志；
- 示波器观察数字信号；
- 逻辑分析仪解码 UART/SPI/I2C；
- HardFault 基础定位；
- 编译错误、链接错误、运行错误的区别。

完成标准：面对“程序不工作”，能够主动提出一套排查顺序，而不是依靠不断修改代码试错。

## Phase 4：FreeRTOS / RTOS

重点理解：

- 为什么需要 RTOS；
- Task；
- Scheduler；
- Priority；
- Queue；
- Semaphore；
- Mutex；
- Event；
- Software Timer；
- 中断与任务之间如何协作；
- 资源竞争；
- 死锁；
- 栈溢出；
- 实时性的基本含义。

完成标准：能够把一个裸机项目改造成多任务结构，并解释任务之间的数据流和同步关系。

## Phase 5：工程化 MCU 开发

开始从“实验代码”转向“真实项目代码”：

- BSP 与驱动层概念；
- HAL 与底层寄存器的关系；
- 模块化；
- 状态机；
- 错误码；
- 日志系统；
- 配置管理；
- Bootloader 基础；
- 固件升级；
- 通信协议设计；
- CRC；
- 超时与重试；
- 异常恢复。

完成标准：做出一个结构清晰、可以持续维护和扩展的 MCU 项目。

## Phase 6：Embedded Linux

在 MCU 基础稳定之后进入：

- Linux 基本命令；
- Shell；
- 文件系统；
- 进程与线程；
- 网络基础；
- GCC / Make / CMake；
- 交叉编译；
- Bootloader；
- Kernel 基础；
- Device Tree；
- Linux Driver；
- GPIO / I2C / SPI / UART 驱动；
- Buildroot / Yocto 基础。

完成标准：能够理解一个典型 ARM Linux 板从上电到应用程序运行的完整链路。

## Phase 7：FPGA 正式入门

前面阶段可零散学习数字逻辑，但从此阶段正式进入 FPGA 主线。

学习顺序：

1. 数字逻辑基础；
2. 组合逻辑与时序逻辑；
3. Verilog；
4. 仿真；
5. FPGA 开发流程；
6. 时钟与复位；
7. 状态机；
8. FIFO；
9. RAM；
10. UART/SPI 等接口逻辑；
11. CDC；
12. Timing Constraint；
13. Timing Analysis；
14. Vivado 调试工具；
15. AXI 基础；
16. FPGA 与 MCU/CPU 协同。

完成标准：能够独立实现、仿真并下载一个包含状态机、缓存和通信接口的小型 FPGA 工程。

## Phase 8：系统级工程能力

最终逐步把能力连起来：

`PC 上位机 ↔ 网络/串口/总线 ↔ MCU/Embedded Linux ↔ FPGA ↔ 真实硬件`

训练重点：

- 系统架构；
- 接口定义；
- 数据链路；
- 时序；
- 性能瓶颈；
- 异常恢复；
- 日志；
- 联调；
- 自动化测试；
- 问题复现；
- 根因分析。

最终目标不是“什么都懂一点”，而是能够跨层定位问题，并在需要时深入其中一个方向。
