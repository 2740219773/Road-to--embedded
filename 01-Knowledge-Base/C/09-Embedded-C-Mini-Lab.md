# Embedded C Mini Lab

Knowledge Base 中的 Mini Lab 只作为快速验证入口；完整课程应放到 Mission / Interactive Lab。

建议在 PC 上完成：

1. 打印变量值与地址。
2. 使用指针修改变量。
3. 用 32-bit 无符号整数模拟寄存器。
4. 分别用 `=`、`|=`、`&= ~` 修改 bit 并比较结果。
5. 定义一个模拟 GPIO 寄存器结构体并通过指针访问。

完成后进入：`04-Missions/Phase-1-C/01-Memory-Detective/Mission.md`，再逐步进入 Bit Hacker 等任务。
