# Knowledge Base

Knowledge Base 是项目的技术知识真相源，不是学习者必须从头到尾阅读的教材。

## 组织方式

```text
System-Map/
C/
Computer-Architecture/
Digital-Logic/
MCU/
RTOS/
Embedded-Linux/
FPGA/
Protocols/
Debugging-Fundamentals/
```

## 规则

- 一个知识点尽量只维护一份；
- Mission、Project、OpenMAIC 通过链接引用；
- 内容优先准确、短、可查询；
- 给出工程使用场景；
- 不承担完整互动体验；
- 外部资料必须记录来源和许可证。

V2.1 期间旧 `01-Fundamentals` ～ `06-Protocols` 的高价值内容将逐步迁入此处。
