# Oscilloscope & Logic Analyzer — 软件之外的证据

两者都能观察数字通信，但回答的问题不同。

## Logic Analyzer 更擅长

长时间数字事件、多个数字通道、协议解码、事件顺序、I2C/SPI/UART/CAN 帧级观察。

## Oscilloscope 更擅长

真实电压、上升/下降沿、过冲、噪声、抖动、模拟质量、时序边界、电源与参考源问题。

## 一个实用判断

```text
“发了什么 bit / frame？” → Logic Analyzer
“这个电平真的像一个可靠的 0/1 吗？” → Oscilloscope
```

实际工程常常两者结合：逻辑分析仪告诉你哪一帧错了，示波器告诉你为什么物理波形让这一帧出错。

## Stage 04 目标

不把仪器当截图工具，而是根据假设主动选择测量点、时间尺度、触发条件和需要验证的量。
