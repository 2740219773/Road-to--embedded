# Instrument Basics — 新手第一次使用测量工具

仪器不是为了让报告看起来更专业，而是为了回答一个软件无法回答的问题：真实引脚或总线到底发生了什么。

## 先选择工具

| 工具 | 最适合回答 | 不适合替代 |
|---|---|---|
| 万用表 | 静态电压、供电、通断 | 捕获短脉冲和协议时序 |
| 示波器 | 电压随时间变化、边沿、频率、占空比 | 自动理解所有协议语义 |
| 逻辑分析仪 | 多路数字时序、UART/I²C/SPI 解码 | 证明模拟电压质量和噪声 |
| Debugger | CPU 位置、变量、寄存器、内存 | 测量真实 Pin 电压 |
| Datasheet / Schematic | Pin、连接、时钟和电气条件 | 代替现场测量 |

## 第一次测静态电压

```text
确认板卡 GND
→ 万用表黑表笔接参考地
→ 红表笔接被测 Pin
→ 先测 Low / High 两种稳定状态
→ 记录电压和软件 Output Register
```

不要把“LED 亮了”当成电压证据。LED 可能是 Active Low，也可能经过板上驱动电路。

## 第一次看 PWM 或 UART

```text
确认被测 Pin 和参考地
→ 选择合适的电压范围
→ 先用较慢、容易观察的信号
→ 测 Frequency / Period / High Time / Duty 或 Bit Time
→ 与程序计算结果比较
```

示波器或逻辑分析仪的地线连接前，先确认被测系统的地关系和隔离条件。未知电源、隔离总线或高压系统不要直接尝试。

## 没有仪器怎么办

- 先用 Debugger 观察变量、寄存器和计数器；
- 用课程中的 PWM、UART、I²C、SPI 和 DMA Lab 建立预测；
- 将结论标记为“软件/仿真证据”，不要写成“真实波形已验证”；
- 等有仪器后，只复测最能区分假设的关键点。

进入 Stage 03 后，必须把软件证据、仪器证据和 Root Cause 分开记录。
