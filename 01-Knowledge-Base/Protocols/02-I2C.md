# I2C — 两根线为什么能挂很多设备

I2C 使用 SDA 与 SCL，在同一总线上通过地址区分设备。

关键概念：Start、Address、R/W、ACK/NACK、Data、Stop，以及 Open-Drain + Pull-up 的电气结构。

## 工程重点

如果只理解协议字节而不理解上拉电阻和 Open-Drain，就很难排查真实 I2C 故障。

## 推荐互动

I2C Bus Visualizer：展示 SDA/SCL、电平释放/拉低、Start/Stop、地址和 ACK；允许关闭 Pull-up，直接观察总线为何无法恢复到高电平。

## 故障视角

NACK 可能来自地址错误、设备未供电、时钟过快、总线被拉死、Pin/AF 配置错误、上拉不合适或设备状态不允许访问。

学习目标是看到 NACK 后知道下一步应该观察什么，而不是立即换一段驱动代码。
