# Stage 08 — System Integrator / 系统集成工程师

最后阶段把 PC、网络、MCU、Embedded Linux、FPGA 和真实设备重新连接成一个系统。

## 核心能力

- 接口定义；
- 数据流和控制流；
- 时序与性能预算；
- 日志与可观测性；
- 跨层故障定位；
- 自动化测试；
- 系统可靠性与恢复。

## Final Boss

构建一个小型完整设备系统：PC 上位机发送控制或采集任务，经通信链路到 MCU/Linux/FPGA，最终驱动或采集真实/模拟硬件。

系统必须包含故障注入与定位报告。目标不是代码量，而是证明自己能够从系统现象跨层找到根因。
