# Programming Warmup — 零基础编程热身

这是进入嵌入式前的短热身，不是完整的 C 语言课程。目标是让完全没有编程经验的学习者能够读懂 Stage 01 的最小代码，并且亲手完成第一次编译和运行。

开始前先完成 [Windows / C 环境检查](../../docs/BEGINNER-SETUP.md)。如果还没有 C 编译器，不要跳过安装和版本确认。

## 通过标准

完成下面五个小练习后，你应该能说明：

- 变量保存什么数据；
- `if` 如何根据条件选择路径；
- 循环为什么会重复执行；
- 函数如何接收输入并产生输出；
- 数组为什么需要从 `0` 开始，并且不能访问边界之外。

## 五个最小练习

可运行样例位于 [examples](examples/README.md)。每个样例都应先预测，再编译，再运行。

每个样例都必须留下：

```text
目标
→ 我的预测
→ 编译命令
→ 实际输出
→ 常见错误
→ 我能解释的原因
```

### 1. 变量

定义一个表示温度的变量，把它改成两个不同的值，写下程序输出如何变化。

### 2. 条件

当温度高于阈值时输出 `ALARM`，否则输出 `OK`。至少测试阈值以下、等于阈值和高于阈值三种情况。

### 3. 循环

让程序输出 0 到 4，并预测循环执行多少次。记录“循环变量”和“执行次数”的区别。

### 4. 函数

写一个接收两个整数并返回较大值的函数。分别测试两个数相等、左边较大和右边较大。

### 5. 数组

创建 4 个元素的数组，访问合法下标 `0`～`3`，然后解释为什么下标 `4` 不属于这个数组。

## 推荐执行命令

从仓库根目录运行：

```powershell
gcc 02-Learning-Path/00-Programming-Warmup/examples/hello.c -o warmup.exe
.\warmup.exe
```

也可以把 `gcc` 替换为 `clang`，或使用 Visual Studio Developer PowerShell 中的 `cl`。

## 记录模板

```text
输入：
我的预测：
实际输出：
不一样的地方：
我现在能解释的原因：
```

不要求在这里学习指针、寄存器、线程或 MCU。完成热身后进入 [Stage 00 — System Explorer](../Stage-00-System-Explorer/README.md)。
