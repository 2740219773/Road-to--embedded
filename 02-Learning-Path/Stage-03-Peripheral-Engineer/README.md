# Stage 03 — Peripheral Engineer / 外设工程师

## 核心目标

让 MCU 真正开始和外部世界通信、采样和控制。

主线：UART → I2C → SPI → ADC → PWM → DMA。

每个外设都采用同一种学习方式：先观察信号和任务，再理解协议，再配置 MCU，最后故意制造故障并用工具定位。

## 典型 Mission

- PC 为什么收到 UART 乱码？
- I2C 设备地址明明正确，为什么没有 ACK？
- SPI 为什么能读到 ID，却读不到正确数据？
- ADC 为什么数值一直抖？
- PWM 占空比变化后，示波器上发生了什么？
- CPU 不搬数据，DMA 为什么还能工作？

## Boss

完成一个多传感器采集节点，通过串口向 PC 持续输出数据，并能够处理至少三种预设故障。
