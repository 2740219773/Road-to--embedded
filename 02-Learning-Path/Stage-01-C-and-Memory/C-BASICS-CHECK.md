# Stage 01 C Basics Check — 进入内存模型前的最小检查

这不是 C 语言考试，而是确认你已经有足够的代码阅读能力。

## 通过条件

请不用搜索资料完成：

1. 说明下面程序的输入、处理和输出；
2. 把 `temperature` 改成 49、50、51，预测三次输出；
3. 写一个返回两个整数中较大值的函数；
4. 解释 `for (int i = 0; i < 4; ++i)` 会执行几次；
5. 说明 `samples[4]` 为什么不是四元素数组的合法访问；
6. 说出 `main`、`#include` 和 `return 0` 的作用；
7. 用 [Learning Record Template](../../docs/LEARNING-RECORD-TEMPLATE.md) 留下一份预测和实际输出。

## 最小通过标准

- 变量、条件、循环、函数、数组 5 个主题至少各能独立解释一次；
- 能运行 Warmup 样例并说明输出为什么如此；
- 不要求此时理解指针、寄存器或 MCU。

未通过时回到 [Programming Warmup](../00-Programming-Warmup/README.md) 和 [C Basics for Beginners](../../01-Knowledge-Base/C/10-C-Basics-for-Beginners.md)。通过后再进入 [C# → C Bridge](../../04-Missions/Stage-01-C-and-Memory/00-CSharp-to-C-Bridge/Mission.md) 或 [Memory Detective](../../04-Missions/Stage-01-C-and-Memory/01-Memory-Detective/Mission.md)。
