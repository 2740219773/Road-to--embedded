这一部分是前期学习主线，目标是建立“软件如何真正控制硬件”的工程直觉。

## 每个外设统一采用的学习模板

### 1. 它解决什么问题？
先理解用途，不先背寄存器。

### 2. 硬件怎么连接？
确认电平、引脚、时钟、上下拉以及必要外围电路。

### 3. MCU 内部发生了什么？
理解对应外设、寄存器、时钟和中断之间的关系。

### 4. 做最小实验
只保留最少代码，把现象跑通。

### 5. 主动制造故障
例如错误波特率、错误引脚、错误时钟、没有上拉、错误中断优先级等。

### 6. 使用工具定位
通过 Debugger、示波器、逻辑分析仪和日志验证猜测。
