# OpenMAIC

这里保存用于 OpenMAIC 互动课堂的课程源材料和生成提示。

## 原则

- OpenMAIC 是互动课堂运行环境之一，不是唯一内容源；
- 技术事实来自 Knowledge Base；
- 教学任务来自 Mission；
- OpenMAIC prompt 负责把两者转换成 Slides、Quiz、AI 角色、PBL 和 HTML Simulation 需求；
- 即使未来更换平台，课程核心仍能保留。

## 推荐目录

```text
Mission-001-Memory-Detective/
  prompt.md
  notes.md
  exports/        # 需要时保存导出说明或索引
```

不要把生成后的大量重复文字重新复制回 Knowledge Base。
