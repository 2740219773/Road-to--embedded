# GitHub Projects — 精选上游项目

这里整理适合 Road to Embedded 路线的公开 GitHub 项目。

原则：**不是把别人的仓库整体搬过来，而是提取值得学习的结构、实验方式和工程思路。** 若未来直接复用受版权保护的代码或内容，需要重新确认对应许可证并保留必要声明。

## learn-embedded-systems

Repository: `iam-sandipmaity/learn-embedded-systems`

适合参考 14 周渐进式学习、STM32 GPIO/中断/RTOS 的阶段安排，以及“学习 + 实验 + 项目”的组织方式。

我们主要借鉴：把 MCU 学习拆细；每阶段增加最小实验、故障实验和调试。

License: MIT。

## Embedded-Engineering-Roadmap

Repository: `m3y54m/Embedded-Engineering-Roadmap`

这是大型嵌入式资源导航，可作为 Embedded C、MCU、RTOS、Linux、调试、协议与硬件基础的上游资料池。

本项目不复制大型链接目录，而是在具体 Stage 需要时精选少量高价值资源。

License: CC BY-SA 4.0。

## Roadmap-to-Embedded-Engineering

Repository: `mateustoin/Roadmap-to-Embedded-Engineering`

值得参考其 Software / Hardware 双基础线，以及 C/C++、Bare Metal、RTOS、Linux、数字逻辑、总线、ADC/DMA/UART/I²C/SPI、Datasheet 与 PCB 基础的整体结构。

核心启发：嵌入式不能只学代码，必须建立“硬件结构 + 软件执行 + 调试工具”的联系。

## embedded-notes

Repository: `Sering-Hong/embedded-notes`

适合作为 STM32、中断、NVIC、ADC、DMA、FreeRTOS、Embedded Linux 等具体主题的中文参考。

## STM32-FreeRTOS-Mastery-Series

Repository: `yunus-kunduz/STM32-FreeRTOS-Mastery-Series`

可参考 Task、Queue、Semaphore、Mutex、Event Group、Software Timer、Task Notification 与双 MCU UART Producer/Consumer 的项目递进方式。

## stm32_portfolio

Repository: `rubin-khadka/stm32_portfolio`

可作为工程题库参考，包括 UART/I²C/SPI/CAN、ADC/DMA/Timer、FreeRTOS、Flash、Bootloader、OTA、Ethernet/TCP、CRC 与传感器项目。

## 本仓库怎么使用这些项目

优先级：

1. 路线借鉴；
2. 实验借鉴；
3. 项目借鉴；
4. 调试方法借鉴；
5. 最后才是实现代码参考。

目标不是收集最多资料，而是形成真正能走完、能动手、能排错的学习路线。
