# 07 — Projects

这一部分用项目把零散知识串起来。

## 项目分级

### Beginner

目标：验证单个知识点。

示例：

- GPIO 按键控制 LED
- 定时器周期任务
- PWM 调光
- UART 回显
- ADC 采样
- SPI/I2C 传感器读取

### Intermediate

目标：同时使用多个外设和软件模块。

示例：

- 传感器采集 + OLED 显示 + UART 日志
- ADC + DMA + 定时器触发
- FreeRTOS 多任务采集系统
- 双 MCU UART/CAN 通信
- SD 卡数据记录器

### Engineering

目标：向真实工程靠近，加入异常处理、协议、日志、升级和上位机联调。

示例：

- MCU 设备控制器 + PC 上位机
- 带 CRC、超时、重试机制的设备通信协议
- Bootloader + 固件升级
- 多节点 CAN 系统
- FPGA + MCU + PC 数据链路

## 项目完成标准

项目不仅要“能运行”，还应尽量包含：

- README 与目标说明；
- 硬件连接；
- 软件结构；
- 调试方法；
- 已知问题；
- 故障注入；
- 测试结果；
- 最终复盘。

后续会从优秀公开项目中筛选适合练习的案例，但优先学习其设计思路，再根据本仓库路线重新实现。
