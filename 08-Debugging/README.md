# 08 — Debugging

调试能力是这个仓库的核心主线之一。

目标不是记住所有故障，而是逐渐建立一套可重复的问题定位方法。

## 基础方法

遇到问题时优先回答：

1. **现象是什么？** 不先猜原因。
2. **正常情况下应该是什么？** 建立对照。
3. **问题稳定复现吗？** 先确认可复现性。
4. **边界在哪里？** 软件、驱动、通信、硬件、时序还是供电？
5. **有什么可以直接测量？** 日志、寄存器、波形、总线数据、引脚电平。
6. **怎样做最小化实验？** 去掉无关模块。
7. **怎样证明根因？** 修复后重新制造故障，验证因果关系。

## 工具

逐步学习：

- IDE Debugger；
- JTAG / SWD；
- 串口日志；
- 万用表；
- 示波器；
- 逻辑分析仪；
- 协议分析；
- Memory / Register Viewer；
- Map 文件；
- Core Dump / Fault 信息。

## Case Study 模板

每个真实问题建议记录：

```text
# 问题标题

## 现象

## 环境与条件

## 最初猜测

## 排查过程

## 关键证据

## 根因

## 修复方法

## 验证方法

## 可复用经验

## 下次遇到类似问题先检查什么
```

长期来看，这一目录会比单纯的知识笔记更有价值。
