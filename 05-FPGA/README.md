# 05 — FPGA

FPGA 是长期目标之一，但前期不与 MCU 主线同时深挖。

## 前期只需要建立的概念

- FPGA 与 MCU 的核心区别；
- 软件顺序执行与硬件并行逻辑的区别；
- 组合逻辑与时序逻辑；
- 时钟和复位；
- HDL 是描述硬件，而不是普通意义上的软件代码；
- 仿真在 FPGA 开发中的重要性。

## 正式学习顺序

1. 数字逻辑基础
2. Verilog
3. Testbench 与仿真
4. FPGA 工程流程
5. 时钟与复位
6. 状态机
7. FIFO / RAM
8. UART / SPI 等接口逻辑
9. CDC
10. 时序约束
11. Timing Analysis
12. Vivado 调试
13. AXI 基础
14. FPGA 与 MCU/CPU 协同

## 特别注意

FPGA 学习不以“代码能综合”为完成标准，需要同时关注：

- 仿真是否正确；
- 时序是否满足；
- 跨时钟域是否安全；
- 真实硬件信号是否与预期一致；
- 设计是否真正表达了想要的硬件结构。

后续在 MCU 主线达到一定阶段后，再把这里拆成完整课程。
