# SPI Timing Playground

用于观察 SPI Mode、CPOL、CPHA、时钟空闲电平和采样边沿之间的关系。

- 运行：浏览器直接打开 `index.html`。
- Stage：`02-Learning-Path/Stage-03-Peripheral-Engineer/`
- Mission：`04-Missions/Stage-03-Peripherals/03-SPI-Wrong-Data/Mission.md`
- Knowledge：`01-Knowledge-Base/Protocols/03-SPI.md`

学习重点不是死背 Mode 0～3，而是能对照 Datasheet 和真实波形判断采样规则是否一致。
