先看“发送端实际发了什么”，再看“接收端按自己的 Baud Rate 在哪里采样”。固定使用最常见的 8N1，重点建立 bit time、LSB first 和 Baud mismatch 的直觉。

1. TX 发送帧

8N1：Idle=1 → Start=0 → 8 Data Bits（LSB first，最低有效位先发）→ Stop=1。

2. RX 采样调查

接收端检测到 Start 后，会按照自己的 bit time 去数据位中间附近采样。TX / RX Baud 不一致时，采样点会逐位漂移。
