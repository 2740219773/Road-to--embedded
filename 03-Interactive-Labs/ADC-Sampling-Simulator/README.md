# ADC Sampling Simulator

用于观察输入电压、Vref、Resolution、Noise 与 ADC Code 的关系。

- 运行：浏览器直接打开 `index.html`。
- Stage：`02-Learning-Path/Stage-03-Peripheral-Engineer/`
- Mission：`04-Missions/Stage-03-Peripherals/04-ADC-Jitter/Mission.md`
- Knowledge：`01-Knowledge-Base/MCU/06-ADC.md`

它只帮助建立量化和噪声直觉；真实 ADC 问题仍需结合电源、接地、源阻抗和示波器测量。
