# Interactive Labs

这里保存可直接操作的可视化与模拟器。

Interactive Lab 与 Mission 分离：Mission 负责教学任务，Lab 负责可重复使用的互动工具。

## 第一批规划

- Memory Visualizer；
- 32-bit Register Playground；
- PWM Visualizer；
- UART Frame Visualizer；
- SPI Timing Explorer；
- Interrupt Timeline；
- DMA Flow Simulator；
- RTOS Scheduler Simulator；
- FPGA FSM Visualizer。

## Lab 原则

- 参数变化必须产生可观察结果；
- 互动服务概念理解，不做装饰；
- 尽量可直接在浏览器运行；
- 一个 Lab 可以被多个 Mission 复用；
- 关键学习逻辑不只存在于 JavaScript 代码中，要在说明文档中保留。
