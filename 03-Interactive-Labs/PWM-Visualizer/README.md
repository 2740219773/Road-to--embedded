# PWM Visualizer

## Beginner Start

- 第一次操作：只改变 Duty Cycle，保持 Frequency 不变；
- 预期观察：High Time、Low Time 和波形宽度变化，Frequency 不变；
- 观察不到：先恢复默认参数，再确认页面没有被浏览器缩放或脚本错误打断；
- Mission Integration：对应 Timer Tick 和 PWM Measurement 的预测阶段。

用于建立 PWM Frequency、Period、Duty Cycle 和 High Time 的直觉，帮助理解这些参数如何影响波形。

- 运行：浏览器直接打开 `index.html`。
- Stage：`02-Learning-Path/Stage-02-MCU-Rookie/`
- Mission：`04-Missions/Stage-02-MCU/04-PWM-Measurement/Mission.md`
- Knowledge：`01-Knowledge-Base/MCU/03-Timer-PWM.md`

## Interactions

操作并调整 Frequency、Period 和 Duty Cycle，观察波形、High Time、Low Time 以及 LED 亮度直觉如何变化。

真实硬件学习时应再用示波器测量频率和占空比，不把动画结果当作真机证据。
