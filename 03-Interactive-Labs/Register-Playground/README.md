# Register Playground

第一批真正可运行的 V2.1 Interactive Lab。

直接在浏览器打开 `index.html` 即可使用，不依赖框架或构建工具。

## 配套 Mission

`04-Missions/Phase-1-C/02-Bit-Hacker/Mission.md`

## 学习目标

让学习者通过操作理解：bit、mask、二进制/十六进制、Set/Clear/Toggle，以及整体赋值和 Read-Modify-Write 的差异。

## 后续增强

- 操作前 Predict 模式；
- 寄存器字段分组；
- 虚拟 LED / GPIO 映射；
- 特殊寄存器写入语义演示；
- Mission 成绩/进度记录。

这个 Lab 同时用于验证一个原则：能通过直接操作理解的概念，不优先用长篇文字解释。
