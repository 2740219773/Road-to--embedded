# 03 — 位运算与寄存器

## 为什么嵌入式特别依赖位运算？

一个 32 位寄存器通常不是只表示一个数字，而是把不同 bit 分配给不同功能。

例如假设：

```text
bit 0：LED 开关
bit 1：蜂鸣器开关
bit 2：电机使能
```

如果只想修改 LED，就不能把整个寄存器随意覆盖。

## 必须掌握的运算

```c
&   按位与
|   按位或
^   按位异或
~   按位取反
<<  左移
>>  右移
```

## 设置某一位

```c
reg |= (1U << 5);
```

含义：把 bit5 置 1，同时尽量保持其他位不变。

## 清除某一位

```c
reg &= ~(1U << 5);
```

## 读取某一位

```c
if (reg & (1U << 5))
{
    // bit5 为 1
}
```

## 切换某一位

```c
reg ^= (1U << 5);
```

## 最小实验

```c
#include <stdio.h>

int main(void)
{
    unsigned int reg = 0;

    reg |= (1U << 3);
    printf("set bit3: 0x%08X\n", reg);

    reg |= (1U << 5);
    printf("set bit5: 0x%08X\n", reg);

    reg &= ~(1U << 3);
    printf("clear bit3: 0x%08X\n", reg);

    return 0;
}
```

每一步先在纸上算，再运行程序验证。

## 联系 MCU

GPIO 模式、UART 使能、中断标志、定时器配置等最终都大量表现为“修改寄存器中的若干 bit”。

以后看到 HAL/LL 库函数时，也要逐渐建立意识：

> 很多库函数最终仍然是在帮我们完成寄存器读写和位操作。

## 练习

假设 `reg = 0x00000000`：

1. 把 bit7 置 1；
2. 把 bit3 和 bit4 同时置 1；
3. 清除 bit4；
4. 判断 bit7 是否为 1；
5. 用十六进制写出每一步的结果。

## 完成标准

看到：

```c
REG |= (1U << 8);
```

能够立刻说出它大致是在“把某个控制位设置为 1”，而不是把它当作普通数学运算。
