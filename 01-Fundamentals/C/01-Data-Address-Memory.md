# 01 — 数据、地址与内存

## 这一课解决什么问题？

嵌入式开发首先要建立一个观念：程序中的变量最终都要落到真实的存储空间中。

```c
int value = 10;
```

不要只把它理解成“创建了一个变量”。更底层地看，是程序需要一块能够保存 `int` 数据的存储空间，并用 `value` 这个名字访问它。

## 必须掌握

- bit、byte；
- 二进制和十六进制；
- 常见整数类型；
- 有符号与无符号；
- 变量的值和变量的地址；
- RAM 的基本作用；
- 地址空间的概念；
- 大小端先建立直觉，不要求深入。

## 最小实验

```c
#include <stdio.h>

int main(void)
{
    int value = 10;

    printf("value = %d\n", value);
    printf("address = %p\n", (void *)&value);
    printf("size = %zu bytes\n", sizeof(value));

    return 0;
}
```

运行多次，观察“值”“地址”“大小”分别是什么。

## 联系 MCU

MCU 内部的 RAM、Flash、GPIO、UART 等资源最终都处在芯片规定的地址空间中。

因此后面学习寄存器时会发现：

> 控制硬件，本质上经常就是按照芯片手册规定的地址读写数据。

## 练习

1. 创建 `char`、`short`、`int`、`long long` 变量，打印 `sizeof`。
2. 分别打印变量的值和地址，解释两者为什么不是同一个东西。
3. 把十进制 `10`、`255`、`1024` 写成十六进制。
4. 思考：如果一个寄存器地址是 `0x40000000`，这个数字更像“数据”还是“位置”？

## 完成标准

能够用自己的话解释：

> 数据存在哪里？地址是什么？为什么嵌入式开发经常看到十六进制地址？
