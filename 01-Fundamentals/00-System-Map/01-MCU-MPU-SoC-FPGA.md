# 01 — MCU、MPU、SoC、FPGA 到底是什么

## 学习目标

完成这一课后，你应该能用自己的话回答：

- MCU、MPU、SoC、FPGA 分别是什么；
- 它们各自适合解决什么问题；
- 为什么有些系统只用 MCU，有些系统需要 Linux，有些系统必须加入 FPGA；
- 上位机、MCU、FPGA 在真实设备中的关系。

---

## 1. 先建立整张地图

一个典型电子系统可以粗略理解为：

```text
PC / 上位机
    ↓ Ethernet / USB / Serial / PCIe
嵌入式处理器（MCU / MPU / SoC）
    ↓ GPIO / SPI / I2C / UART / CAN / Memory Bus
传感器、执行器、ADC、DAC、存储器
    ↓
真实物理世界
```

当数据速率、并行度或实时性继续提高时，系统中可能加入 FPGA：

```text
PC / 上位机
       ↓
MCU / SoC  ←→  FPGA
                 ↓
        高速 ADC / DAC / 数字接口
```

这张图非常重要。后面学习的绝大多数知识，最终都可以放回这张图里。

---

## 2. MCU

MCU（Microcontroller Unit，微控制器）可以理解成“一颗面向控制任务的小型计算机芯片”。

通常内部已经集成：

- CPU；
- Flash；
- RAM；
- GPIO；
- 定时器；
- UART；
- SPI；
- I2C；
- ADC 等外设。

常见系列：

- STM32；
- GD32；
- NXP MCU；
- ESP32；
- AVR；
- MSP430。

### MCU 适合什么

典型场景：

- 控制电机；
- 读取传感器；
- 控制继电器；
- 实现串口、CAN、Modbus 等通信；
- 做实时控制；
- 设备状态机。

### 一个重要认识

MCU 并不等于 STM32。

STM32 只是 MCU 中非常重要的一类产品。

---

## 3. MPU

MPU（Microprocessor Unit，微处理器）通常拥有更强的 CPU，但往往需要外部 DDR、Flash 等器件组成完整系统。

典型特点：

- 性能更高；
- 可以运行 Linux；
- 内存更大；
- 软件系统更复杂；
- 通常具有 MMU 等硬件能力。

例如很多 ARM Cortex-A 系列处理器都属于这一方向。

MPU 更接近“缩小版 PC”。

---

## 4. SoC

SoC（System on Chip，片上系统）是一个更广义的概念。

它把一个完整系统中的大量功能集成到一颗芯片中，例如：

- CPU；
- GPU；
- 内存控制器；
- 视频模块；
- USB；
- Ethernet；
- AI 加速器；
- 其他专用硬件。

树莓派等 Linux 开发板背后的主芯片通常属于 SoC。

需要注意：MCU 本身从某种意义上也可以看作一种高度集成的 SoC，但工程领域通常还是会把 MCU 与运行复杂操作系统的 SoC 区分开来讨论。

---

## 5. FPGA

FPGA（Field Programmable Gate Array，现场可编程门阵列）与 MCU 的思维方式完全不同。

MCU 的核心思路是：

> CPU 一条一条执行指令。

FPGA 的核心思路更接近：

> 用逻辑资源搭出真正并行工作的数字电路。

例如 MCU 写：

```c
A();
B();
C();
```

通常意味着先执行 A，再执行 B，再执行 C。

而 FPGA 可以让 A、B、C 三部分硬件同时工作。

### FPGA 特别适合

- 高速数据采集；
- 高速数字信号处理；
- 大规模并行计算；
- 精确定时；
- 高速通信接口；
- 自定义数字协议；
- ADC / DAC 高速接口；
- 雷达、通信、图像、测试测量设备。

---

## 6. MCU 和 FPGA 不是替代关系

真实工程里经常是协同工作：

```text
FPGA：
高速、并行、严格时序、海量数据

MCU：
控制、配置、状态管理、通信、业务逻辑

PC：
界面、数据展示、配置、数据库、复杂业务
```

这也是本项目最终要形成的能力链：

```text
上位机
  ↓
嵌入式控制
  ↓
FPGA / 数字逻辑
  ↓
真实硬件
```

## 动手练习

### 练习 1

找一台你身边的设备，例如示波器、电源、路由器或电机控制器，尝试画出：

```text
上位机 / 用户界面
        ↓
处理器
        ↓
外设 / FPGA / ADC / DAC
        ↓
物理设备
```

不要求完全正确，只要求开始建立系统分层意识。

### 练习 2

分别给下面任务选择更适合的核心器件，并说明原因：

1. 控制 8 路继电器；
2. 实时采集 1 GSPS ADC 数据；
3. 做一台带触摸屏和网络功能的复杂设备；
4. 读取温度传感器并通过 Modbus 上传。

## 完成标准

如果你已经能不查资料解释下面四句话，这一课就算完成：

- MCU 是什么；
- Linux 为什么通常不跑在普通低端 MCU 上；
- FPGA 与 CPU 最大的思维区别是什么；
- MCU、FPGA、PC 在一个设备里为什么经常同时存在。

不要背定义，要真正理解它们在系统里分别承担什么角色。
