# 01 — Fundamentals

这一部分用于补齐进入嵌入式开发前最关键的基础知识。

## 学习范围

### C 语言

重点关注嵌入式中高频使用的内容：

- 指针与地址；
- 数组、结构体；
- 位运算；
- `const`、`volatile`、`static`；
- 多文件工程；
- 内存与作用域；
- 编译与链接。

### 计算机组成基础

需要理解：

- CPU 如何执行程序；
- RAM 与 Flash 的区别；
- 寄存器是什么；
- 总线是什么；
- 中断为什么存在；
- 栈与函数调用的基本关系。

### 数字电路基础

为 MCU 与 FPGA 都服务：

- 二进制与十六进制；
- 与、或、非、异或；
- 组合逻辑；
- 时序逻辑；
- 触发器；
- 时钟；
- 建立时间、保持时间的概念。

### Linux 基础

前期只建立基本使用能力：

- 文件和目录；
- 常见 Shell 命令；
- 权限；
- 进程；
- GCC；
- Make/CMake 基础。

## 学习原则

不追求把大学课程完整重学一遍。每个知识点都要回答：

> 这个知识在真实嵌入式项目里什么时候会用到？

如果暂时回答不了，就先保留概念，不必无限深入。
