# Projects

Projects 用于验证多个知识点能否被组合成真实工程能力。

## 分层

```text
Beginner/
Intermediate/
Advanced/
Boss/
```

## 项目要求

每个核心项目尽量包含：

- Requirement；
- Constraints；
- Architecture；
- Milestones；
- Acceptance Criteria；
- Failure Injection；
- Debug Notes；
- Retrospective。

项目不以“代码能运行”为唯一完成标准，还需要说明如何验证、出现故障如何定位，以及哪些设计可以迁移到其他系统。
